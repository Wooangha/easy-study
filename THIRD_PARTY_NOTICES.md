## PDF engine: `@embedpdf/pdfium` 2.15.1 (PDFium compiled to WebAssembly)

easy-study reads PDFs with PDFium compiled to WebAssembly, from the npm package `@embedpdf/pdfium`
(pinned to exactly 2.15.1 in `package.json`; `node_modules/@embedpdf/pdfium/dist/pdfium.wasm` and its JavaScript
glue). The package ships two license files, reproduced verbatim below: `LICENSE` (the package, MIT) and
`LICENSE.pdfium` (PDFium, BSD-3-Clause and Apache-2.0).

PDFium compiles several third-party libraries into the same `pdfium.wasm`; the package does not ship their license
texts, so they follow after PDFium's: FreeType, Anti-Grain Geometry, Little CMS, libjpeg-turbo, OpenJPEG, libpng and
zlib — the libraries of PDFium's `third_party/` directory that its rendering uses (FreeType, Little CMS, OpenJPEG,
libpng and zlib can be recognized by their messages inside `pdfium.wasm`; libjpeg-turbo decodes JPEG images and AGG
is PDFium's default rasterizer). The texts are the upstream projects' current license files; the versions built into PDFium may carry
earlier copyright years. When the pinned version changes, check the package's `LICENSE*` files again and update this
file.

  <https://ffmpeg.org/releases/ffmpeg-8.1.tar.xz> (SHA-256
